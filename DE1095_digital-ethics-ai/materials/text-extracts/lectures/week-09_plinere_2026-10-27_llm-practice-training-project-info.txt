What is an LLM?
An LLM (large language model) is a model that predicts the next token of a
text.
• Input: a text, the prompt.
• Output: its continuation, the completion.
• A language model encodes statistical information about language: given “My favorite color is __”, it predicts “blue”
more often than “car”.
4
How does it work? One simple idea
Phone keyboard  LLM
Suggests the next word while you type  The same idea, trained on a huge amount of text
• It predicts the next token, again and again.
• It uses statistical patterns learned from text, not understanding.
5
Completion: many tasks are continuing a text
Translation, summarization and coding can be framed as completion tasks.
• Prompt: “To be or not to be” → completion: “, that is the question.”
• Prompt: “How are you in French is …” → completion: “Comment ça va”
• A completion is a prediction based on probabilities. It is not guaranteed to be correct.

Before attention (seq2seq): the encoder reads the input and the decoder writes the output. Both parts are recurrent: they work one
token at a time.
Attention (2015) added one thing: the decoder looks at all states of the encoder, not at one summary.
Transformer (2017) keeps the structure “encoder in, decoder out”, but removes the recurrent part: only attention is left.
GPT (2018) is a transformer without the encoder: only the decoder is left.

Self-attention: tokens look at other tokens
Each token looks at all other tokens to understand its context.
• Think of words casting votes on how important other words are for their meaning.
• In “The cat sat”, “sat” is linked to “cat”: the cat is the one who sat.

Information flows left to right
Masking: a token gets information only from the tokens to its left.
• GPT-style models are unidirectional: they read left to right.
• So the order of information in the prompt matters.
• Not the same as a masked language model, which fills in a missing token using context on both sides.
