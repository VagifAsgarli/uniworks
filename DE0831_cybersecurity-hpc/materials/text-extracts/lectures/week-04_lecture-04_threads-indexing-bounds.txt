A Complete Launch and Validation
using CUDA
host = Int32[0, 2, 7, 1, 5, 0, 8, 3]
failed_d = CuArray(host)
flags_d = CUDA.zeros(Bool, length(host))
threads = 4  # 256 for real inputs
blocks = cld(length(host), threads) # 2 blocks
@cuda threads=threads blocks=blocks flag_kernel!(
flags_d, failed_d, Int32(5))
CUDA.synchronize()
@assert Array(flags_d) == (host .>= 5)
Allocate on the host, launch on the device, validate against a CPU
reference.
Compilation failures: device code and compiler inspection.
