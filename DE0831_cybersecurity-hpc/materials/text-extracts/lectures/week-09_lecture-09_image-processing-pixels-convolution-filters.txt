From Bytes to Float32
Byte arithmetic wraps: in UInt8, 200 + 100 = 44, so a sum of
neighbours overflows before it is divided
Kernels compute in Float32: 4 bytes per pixel, 8.3 MB per 1080p
frame, and convert back to bytes only for storage or display
The conversion is a point operation: one broadcast, no kernel to
write

Zero padding: treats the outside as black; leaves a dark rim after a blur and a false edge
along the border after a gradient

Naive Convolution Kernel
const R = 2  # radius 2: a 5 x 5 filter
function convolve!(out, F, w)  # w: 5 x 5 weights, sum 1
r = (blockIdx().x - Int32(1)) * blockDim().x + threadIdx().x
c = (blockIdx().y - Int32(1)) * blockDim().y + threadIdx().y
H, W = size(F)
if r <= H && c <= W
acc = 0f0
for j in -R:R, i in -R:R
rr = clamp(r + i, 1, H) # clamp to edge
cc = clamp(c + j, 1, W)
@inbounds acc += w[i + R + 1, j + R + 1] * F[rr, cc]
end
@inbounds out[r, c] = acc
end
return nothing
end
